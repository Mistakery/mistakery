# Интеграция ресурсных концовок — 2026-10-04

## Утверждённый поток

Обычный маршрут уже завершает забег после подтверждения сюжетного исхода или последнего ответа всей filler-цепочки. Представление завершённого забега теперь использует те же шесть карточек, что и изолированное превью:

| endingId | Карточка |
|---|---|
| cash_low | DOC_LOSS_1 |
| team_low | DOC_LOSS_2 |
| team_high | DOC_LOSS_3 |
| customers_low | DOC_LOSS_4 |
| founder_low | DOC_LOSS_5 |
| founder_high | DOC_LOSS_6 |

Карточка сохраняет доставку, исходящие сообщения и авторские паузы. После доставки — один красный импульс 1,3 с, короткое встряхивание и остаточная виньетка. Повторный render сохраняет виньетку без повторного импульса.

Любой из двух ответов открывает центральный b2buddy-попап. Never again и Let’s cook в обычной и тестовой игре начинают новый забег сразу на первом сюжете, после обоих Saved: новый seed/opener, ресурсы 25/60/15/65, пустая история, без стоимости ответа. Escape только закрывает попап и сохраняет завершённый забег. Изолированное превью остаётся без перехода в игру. Верхний Back to 9–5 запускает существующий новый забег через Saved. В превью он по-прежнему называется Replay card.

Состояние представления хранится отдельно от маршрута; тестовый Back переносит его вместе со снимком. Навигация очищает dialog, observer, таймер доставки, red overlay и атрибут оформления. Judgment Day использует прежний немедленный финал. Cash/Customers 100 не получили новых концовок.

## Проверки

`tests/resource-endings.browser.test.cjs` проходит реальные witness-последовательности для всех шести границ и Judgment Day в Chromium/WebKit. Проверяются оба ответа карточки, рестарт обеими кнопками попапа без Saved и списания, отсутствие автоматического ответа на первый сюжет, повторный render, RU-инспектор, Back, restart и геометрия.

Отдельный сценарий без preview/test URL проверяет исходящие Founder 100, паузы 650/2500 мс, skip, один full-screen pulse, Escape, фокус, попап при 320×480 / 320×650 / 1280×900 и перезапуск посреди доставки Founder 0. Прежние unit-тесты проверяют signed ledger, восстановление внутри эпизода, simultaneous causes и Judgment Day priority. Прежние preview-тесты проверяют все авторские карточки, reduced motion и изоляцию.

Ручной HTTP-путь к финалу: `http://127.0.0.1:8791/?seed=809`, обычное вступление → Saved → отказ от Padel → подтверждение → Buy it back. Cash 0 открывает DOC_LOSS_1; Need CEO? открывает попап.
